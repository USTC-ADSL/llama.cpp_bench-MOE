# Activation Arena and Fused Reduction

## Scope

fd8657d6, Qwen1.5-MoE Q4_0, fixed prompt, single request, full 24-layer Transformer including attention, router and last-token logits. Resident offline Expert placement with real online routing; shared activations and direct callback I/O enabled throughout. Last-layer FFN processes one token, as in native inference. Two warmups per process; loading, weight conversion and KV reset outside timing. Frequencies are not locked. These are improvements to the resident experimental executor, not a throughput claim for the bounded dynamic weight-conversion runtime.

## Cross-Layer Arena

Each backend reserves the largest layer graph requirement, conservatively allowing all 4*T routed pairs plus shared computation where applicable. Graph metadata and backend tensor extras remain independent; only backing storage is reused after all backend jobs and host aggregation complete. Padding of reused ID storage is cleared on each invocation. No backend buffer reset or graph rebinding is used.

256-token separate/arena/arena/separate process order (12 timed calls each):

| Process | Median ms | Expert activation backing MiB |
|---|---:|---:|
| separate-a | 569.728 | 1259.475 |
| arena-a | 570.649 | 120.245 |
| arena-b | 572.646 | 120.245 |

Backing allocation decreases by 90.45%; capacities CPU/NPU/GPU are 34,082,816 / 57,678,848 / 34,324,480 bytes. First latency comparison is neutral; the second is subject to drift. No stable arena speedup claim. All four final logits are byte-identical (SHA256 `52ac1bdd652099402c8556176f8cad745256088a26b2fd2c521a698994139219`). This measures explicit Expert graph buffers, not total device RAM, weight storage, driver scratch or allocator overhead.

At128 the arena is 55.0068 MiB, versus 629.7653 MiB for separate buffers (91.27% reduction). The final-binary arena run checks every warmup/timed logits against its first round and matches historical shared-final-a. A separate-buffer regression follows it; its logits match, and median is 416.982 ms, while arena with original aggregation is 401.338 ms. This sequential comparison is not sufficient to establish causality.

## Fused Host Reduction

Keep the original top-k FMA accumulation order and add shared output last, but fuse all contributions per token into one vectorized output write. Original aggregation remains a selectable control. Every measured group uses ABBA: original, fused, fused, original. Both variants share weights, arenas and direct callback I/O in one process. All round logits must match bitwise before a report is accepted.

| Tokens / process | Original mean ms | Fused mean ms | Original/fused combine ms | Mean saved ms | Positive ABBA groups |
|---|---:|---:|---:|---:|---:|
| 256 / A | 583.356 | 562.605 | 31.256 / 10.855 | 20.751 | 6/6 |
| 256 / B | 618.751 | 589.306 | 36.306 / 11.014 | 29.446 | 6/6 |
| 128 / A | 401.652 | 396.390 | 12.828 / 4.615 | 5.262 | 4/6 |

256 A reduces mean full-model latency by 3.56%; 20.40 ms of 20.75 ms saved is attributable to measured aggregation. Median-derived throughput is 439.01 -> 453.47 token/s. Independent process B reduces mean latency by 4.76%, with 25.29 ms of 29.45 ms saved in aggregation and median-derived throughput 409.85 -> 433.19 token/s. All 12 ABBA groups are positive despite absolute drift between processes. At128 host aggregation is faster, but end-to-end improvement is not stable across groups. All three ABBA runs have byte-identical warmup/timed logits and match their unoptimized references.

Raw reports, command manifests, logs and logits are under `evidence/`. `reduce-summary128.json` and `reduce-summary256.json` are generated by `tests/check-callback-pairs.py --host-reduce`; they verify identical token IDs, placements, logits, ABBA order and fixed post-warmup allocation counts. Historical128 reference: `../handoff-2026-09-24-offline-shared-activation/evidence/shared-final-a.json.gz`.

## Remaining Bottlenecks

Shared memory, direct callback I/O and reduction fusion each remove different host costs; their independently measured effects must not be added. Arena reuse addresses capacity, not execution critical-path length. Native graph boundaries, input gather, backend synchronization and the slowest parallel Expert branch remain. The next meaningful experiment is graph-boundary/gather integration with the same numerical and paired controls, rather than additional weight replication. No fresh native-NPU comparison was run in this cohort, so the numbers above are incremental gains over the existing heterogeneous executor, not a new all-NPU speedup claim.
