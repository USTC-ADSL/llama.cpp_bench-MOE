# 预加载运行状态校正：预测有效，但未证明新增调度收益

fd8657d6，Qwen1.5-MoE Q4_0，单请求、完整24层 Transformer，真实在线 router。权重在计时前准备并常驻。本轮不修改算子、logits 或权重转换；只改实验调度器的耗时预测。校准后冻结模型，再验证未参与拟合的 harbor prompt。

## 吞吐与具体分配

每个进程8次正式计时、2次预热；两轮采用 native/custom/auto 与反向顺序。自动路径时间为含前后状态采样的请求中位数，加一次设备端决策；基线为全 NPU 计算中位数。加载/转换、预热、离线路由捕获、模型/路由文件 I/O 和报告序列化不计入。此处不是启动进程到输出的冷启动延迟。

128的层0–22：按当前离线路由的token数升序、Expert ID打破平局，将24个低负载routed Experts给CPU；层5、17改为32个。其余routed给NPU，shared给GPU，各后端独立gather后立即启动计算。层23仅处理一个输出token，routed NPU/shared CPU。768的强制异构候选为层0–22每层CPU tail4、其余routed NPU/shared GPU，末层同上；自动模式两轮均拒绝该候选，实际使用原生NPU并关闭所有custom执行开关。

决策成本128为5.35/5.97ms，768为11.87/12.34ms；每请求前后采样约4.6–5.0ms。模型已计入其使用的观测和规划成本；周边`getrusage`及JSON输出等不在该范围内。

**768的+2.41%不能写为异构调度收益**：实际执行的是同一原生路径，独立进程间状态变化使其计算时间不同。强制异构相对各自NPU对照为+0.48%/+2.08%，未加决策费用；保护策略可能错过小收益，仍未证明逐次最优或768稳定异构加速。本轮128/768的实际选择与未加状态校正的restricted guard相同，没有证明新增状态模块改变选择后带来了额外吞吐提升。

## 模型与独立验证

保留原关键路径模型及模板覆盖保护，只增加两个小型残差模型：`T = T_guard × exp(beta·x)`，`x=[1, I(tokens=768), (quiet_therm_C−35)/10, 1−policy0频率/硬件上限, 1−policy6频率/硬件上限]`。倍率限制在0.5–2。数据不全、超过决策时效或越出校准域时使用原restricted guard。

A的4轮、B的3轮共28个进程，每个进程的中位数构成一个观测。A拟合；B只有在MAPE降低至少10%、最大APE不超过bias模型1.25倍时才选状态模型，否则使用只有截距与长度偏差的bias模型。没有把同一个preload快照下的8次计时当作8个独立训练点。

## 能解释什么，下一步做什么

CPU频率分别来自policy0（CPU0–5）和policy6（CPU6–7）；`skin_c`实际为`quiet_therm`，不是HAL综合skin温度。GPU/NPU时钟不可读，保持null。所有28个校准preload的policy6频率都相同，其系数约为零，未学到该频率域对耗时的影响。

预加载观测到第一轮正式计时相隔7.30–13.27秒；加载和预热可能改变状态。1秒时效检查针对采样到决策，不能解释为采样到推理不到1秒。当前采样对异构路径有有限预测价值，对NPU波动缺乏可靠解释；不能据此声称温度或DVFS已被因果定位。

下一阶段优先考虑**执行就绪时可获得的低成本反馈**，而非继续堆温度特征：先分析已有逐轮记录中“上一轮残差预测下一轮”的收益与漂移时效，再将在线反馈接入真实可执行的放置选项。禁止用本轮结束时间解释本轮选择。若改变Expert后端，必须显式处理权重准备/驻留与迁移费用；不能假定加载后切换路径免费。冷启动单请求没有历史时仍保留当前覆盖/误差保护。低成本CPU采样和NPU代理探测需要单独消融并计费，尚未证明有效。

## 正确性与证据

23个原模型和13个新状态校正Android/Python契约通过；四次真实auto的Python/C++分配、费用与状态结果一致。auto与同轮匹配的强制路径完整logits逐字节相等；遥测开关的两个pilot完整logits也相等。跨后端custom与NPU的NRMSE为128的0.02804、768的0.02089，本次top1一致；不代表通用生成质量等价。

共44个成功完整模型进程：28个校准、12个确认计时、2个路由捕获、2个早期pilot（pilot二进制不同，已从拟合排除）。确认所有实际执行开关和Expert分配与计划一致，所有校准来源哈希通过复核。128/768强制异构Expert激活缓冲约28.25/169.52MiB；这不是总额外内存上限。本轮不增加完整三后端权重副本。
