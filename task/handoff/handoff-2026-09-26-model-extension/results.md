## 本轮修改

1. 保留旧模型的基础系数和 128/256/512 校准节点，仅增加 technical prompt 的 1024 节点，节点间插值，禁止区间外外推。部署 JSON 为 **14,369 bytes**。在计时前固定模型，没有用 museum/programming 的执行时间调整参数。
2. 给校准执行族增加 shared 后端约束：CPU routed 尾组配 shared GPU，GPU routed 尾组配 shared NPU，routed 全 NPU 分支配 shared GPU。旧 CPU 族各长度均为 shared GPU；新 1024 初次选成 shared NPU，直接插值会混合不等价路径。补测缺少的两组 technical1024 CPU/sharedGPU 后才开始确认测试。旧结果保留在 `evidence/pre-family-coverage/`，更慢的新校准没有被丢弃。该限制不是全组合最优搜索。
3. 增加 `--activation-lifetimes`：在跨层共享池内，按张量存活区间进一步复用图内中间空间。输入从时刻零存活、view 延长根存储生命周期、输出保留至 host 聚合。分别固定 split/native/shared-only 的最大形状布局，小形状绑定相同槽位并检查类型、算子、区间和容量。不能独立重排每个小形状后只按端点预留容量，因为碎片使容量不单调。

| Case | 常规 0–22 层 routed 分配 | shared |

## 长输入与复用消融

在 768，模型预测 custom 约 1161 ms、native 约 1120 ms，加入经验波动余量后选择原生。**确实触发了回退，但不能说原生每次都最快。** 强制 custom 的纯执行时间 museum 为 1090.401/1278.501 ms，programming 为 1257.419/1183.856 ms；相对 NPU 吞吐分别 −1.27%/−8.86%、−0.94%/+5.08%。programming-B 的强制异构更快，说明当前余量策略可能保守，尚未证明全局最优。

池容量均减少 **35.43%**，logits 与相同映射的未复用版本逐字节一致。但延迟有升有降，programming768 两次反而都慢，因此本优化目前只能主张内存收益。该池低于 200 MiB **不等于全部额外内存低于 200 MB**；没有测量总 RSS 上限。`summary.json` 对 lifetime 的 accounted 时间另外加决策，而 forced 未加；此消融表统一使用纯执行时间，避免混口径。

## 正确性与验证边界

- 34 进程退出零，模型/训练源/库/二进制哈希、Python/C++ 计划与预测、24 层 owner、实际 top-k pair 账本、固定样本数通过审计；同策略 A/B 输出一致。自定义路径各轮输出一致、计时阶段无新增 Expert 图分配。
- 所有复用对照的输出与**同映射**基线逐字节一致；768 自动原生输出与原生基线一致。不要求异构与原生或 CPU 逐字节相同。
- Android 布局单测覆盖 rows1/17/768/1024、较晚读取输入、嵌套 view、多个输出和最大布局绑定小形状。另测全24层 routed/shared 同在 NPU 的128-token native图，复用前后27.503→16.002 MiB、logits一致；仅功能测试，不混入性能结论。9 个上下文模型单测通过。
- 相对 CPU 捕获，自动方案 logit NRMSE：museum128/384/768 为 **8.687%/3.720%/4.381%**；programming 为 **7.593%/6.715%/10.079%**。museum128 原生 NPU top-1=16、CPU/异构=80101；programming768 原生/异构=3082、CPU=1965。其余自动方案 top-1 与 CPU 一致。这是实际数值差异，尚无困惑度或生成质量验证，不能仅凭吞吐宣布模型质量等价。
- 模型选择与反馈仍不是在线权重迁移调度器；未测 decode、多请求或超过1024。最后层仅一个 FFN token，不能将全模型时长简单除以24当作相同层耗时。

## 后续优先方向

先补跨后端数值误差与短生成质量验证；同时用逐层后端墙钟和端到端残差定位长输入的实际关键路径。优化上优先减少 host gather/聚合及图切分成本，比较 NPU 内完成聚合与按 token 分块流水；必须测共享带宽竞争，不能只套用理想 `max(T_cpu,T_gpu,T_npu)`。再引入有驻留约束的在线选择，以实测收益是否覆盖准备/同步成本决定迁移；权重转换继续作为独立模块输出成本和可行性，不扩张当前回归模型。图内复用先作为内存优化保留，不为声称加速重复调参。
