# 三端共享权重布局中间层

## 目标与验收约束

- 中间层独立于 MoE；MoE/专家预测/路由是上层使用者。
- 最终 CPU、OpenCL GPU、HTP NPU 消费同一份物理权重布局。长期只保留一份完整权重，允许固定上限的临时缓冲、寄存器/片上整理及加载时转换。磁盘格式不受限制。
- 允许修改三端计算内核；原始实现必须可回退。
- CPU 辅助预测、预取或整理限于一两个小核可以承担的规模，不能依赖全核重计算隐藏成本。CPU 自身算子的原生基准另行固定线程配置。
- 各端算子计算耗时相对于该端最佳有效原生路径，退化不得超过 5%。禁止使用端到端 I/O 收益抵消算子退化；调用时必要的数据整理须计入并单列。
- 第一阶段 Q4_0、普通矩阵乘、单 token decode 与批量 prefill，设备 Redmi K80 Pro `fd8657d6`。正确性、真实权重存储数量与临时空间同时验收。
- 性能目标是待验证的研发目标，未通过时明确记录，不能将功能原型标成完成。
