# Resident route-cost model: implementation

Goal: calibrate a small placement model and validate unseen routes and full-model Prefill on fd8657d6. Weight conversion is excluded from the first cost fit, with explicit eligibility/preparation-cost interfaces. No weight replication to all three backends is introduced in full-model execution.

Model: for placement P, predict `T(P)=max_b f_b(route_group_b, shared_b, concurrent_work)+h(P)`. Each `f_b` is ridge regression with 26 shape/load/concurrency features; `h` has 8 gather/reduction/join features. Backend targets are measured concurrently, not summed standalone timings. Features contain pair count, active Expert count, padded counts at 8/32 rows, max/second moment, compact bank width, native/grouped shape, shared work, co-running CPU/NPU/GPU demand. Fixed architecture and Q4_0; no Expert IDs or layer IDs are fitted. Cross-validation selects ridge strength on calibration layers. Python fits; C++ executes the same small dot products and bounded joint candidate search.

Candidates: 9 whole-routed/shared combinations plus tails of 1/4/8/16/24/32 least-loaded active Experts to CPU or GPU, remainder NPU, shared NPU/GPU. At most 33 candidates. This is a restricted design space, not a global optimizer. Future online callers supply actual backend eligibility for each Expert/shared branch. A nonresident candidate without an explicit preparation-cost entry is rejected. Current offline prediction allows all destinations BEFORE preparing selected resident banks; it is not online migration.

Implementation:
- `tests/fullmodel-oracle.cpp`: `profile` replays captured real FFNs with compact weights, shared arenas, direct output and fused reduction; two warmups, explicit per-backend phases and whole-call measurements. `predict` reads a frozen cost model and route captures, times device decisions and emits plans compatible with full-model confirmation.
- `tests/moe-placement-model.{h,py}`: matching C++/Python predictors, route-conditioned candidate generation, ridge calibration, held-out ranking audit, explicit availability/preparation cost.
- `tests/run-fullmodel-oracle.py`: profile layer selection and cost-model deployment/hash recording.
- `tests/run-moe-placement-study.py`: sequential resumable calibration, validation and fullmodel stages. Technical prompt calibration at128/256/512, layers0/3/11/19/23. Narrative evaluation at128/512, layers1/7/15/21. Plans generated before target candidate measurements; model must remain frozen.
- `tests/test-moe-placement-model.py`: critical-path max, unavailable fallback rejection, preparation cost, actual tail identity.
