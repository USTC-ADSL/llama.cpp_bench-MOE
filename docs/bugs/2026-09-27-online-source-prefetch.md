# Online canonical source prefault duplicates residency

**Symptom/trigger.** Full online MoE already stores canonical Expert bytes in DMA, but later model loading prefaults its unused GGUF Expert mapping. Initialization peak RSS reaches3.75–3.95GiB, and CPU output weights can be swapped out. Comparing native/online first prefill without checking residency can mistake paging cost for heterogeneous speedup.

**Root cause.** `llama_model_base::load_tensors` unconditionally requested mmap prefetch. Without lazy tensor ranges, mmap uses MAP_POPULATE. Releasing only the prototype's first mapping did not prevent the later loader mapping from faulting the source again. Whole-file source residency is unnecessary when Experts are supplied by the custom graph callback.

**Fix.** Add default-false `llama_model_params.no_mmap_prefetch`; use it in the loader. The benchmark opts both comparison modes out of full prefetch. Canonical import calls an optional source-release callback per matrix, using MADV_DONTNEED on its owned mapping plus file-range POSIX_FADV_DONTNEED. A shared-source option imports canonical bytes into DMA while retaining only one converted GPU layer bank. Report advice failures, source-cache residency samples, RSS/PSS and the scoped buffer account. An optional symmetric output-page touch reports restoration time and restoration+prefill separately, without prompt execution or Expert warmup. CPU_REPACK intentionally does not advertise generic host layout; the control explicitly recognizes its CPU-owned allocation rather than assuming every backend pointer is host memory.

**Validation.** Incremental Android llama and HTPv79 builds, manual NDK benchmark/probe builds and Python syntax checks passed. fd8657d6 full-model bounded-source development logits match the earlier prototype exactly. New river/library confirmation has deterministic logits within each backend, successful144 source-release calls per online run, successful mincore queries,1.31–19.78MiB sampled duplicate Expert file-cache pages and832–836MiB online peak RSS. Restored canonical kernel passes12 matrix cases and layout/copy/GPU conversion guards. See `task/handoff/handoff-2026-09-27-online-weights/results.md`, run manifests and logs for exact commands/results.

**Limits.** Advice is not a physical-memory hard cap. The72.26MiB reported buffer allowance excludes some common/driver/initialization memory; RSS excludes much DMA. Matched resident-output confirmation still shows−8.34%/−0.12% throughput relative to native, so first-pass speedup acceptance remains unmet. Cross-backend quality equivalence is not established. Default prefetch semantics remain enabled for ordinary callers; users of changed public model parameters should rebuild against the matching library.
